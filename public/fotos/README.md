# Fotos dos integrantes

Coloque as fotos nesta pasta. O nome do arquivo deve ser exatamente o nome cadastrado para o integrante, incluindo espaços e acentos.

Por exemplo, para **João Victor**, use `João Victor.jpg`. Para **Maria Clara**, use `Maria Clara.png`.

Os formatos aceitos são `.jpg`, `.jpeg`, `.png` e `.webp`. Também são reconhecidas as extensões `.JPG` e `.PNG`. Prefira arquivos quadrados, com o rosto centralizado: a ferramenta recorta a foto em círculo.

Se houver mais de um formato com o mesmo nome, a busca segue esta ordem: JPG, JPEG, PNG e WebP. Se a foto não existir ou não puder ser carregada, serão exibidas as iniciais do integrante sobre uma cor pastel.

Depois de adicionar ou substituir as fotos, publique novamente os arquivos do projeto. Ao alterar o nome de um integrante no Planner, renomeie também o arquivo da foto.

Esta pasta não contém fotos pessoais de exemplo.
